Your key responsibilities

Design and implement integration solutions using REST/SOAP APIs, message queues, and event-driven architectures.
Develop and maintain microservices, connectors, and adapters for SaaS, ERP, CRM, and legacy systems.

Design, build, and maintain CI/CD pipelines for integration components using GitHub Actions, Azure DevOps, or Jenkins, including automated testing, security scanning, and release management.
Provision and manage cloud infrastructure using Infrastructure-as-Code (Terraform, Bicep, ARM, or CloudFormation) to support integration workloads.
Containerize and deploy integration services on Kubernetes (AKS/EKS/GKE) with Helm charts and GitOps workflows (ArgoCD/Flux).
Ensure integrations meet security, performance, observability, and compliance standards.
Troubleshoot, optimize, and document integration flows, contracts, deployment pipelines, and operational runbooks.
